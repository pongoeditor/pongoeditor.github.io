Welcome to PongoFileShare

PongoFileShare is a lightweight Windows desktop application that helps you upload files to a personal file-sharing space and gives you back a public link that anyone can open in a browser. No complicated setup, no command lines required — just pick a file, click upload, and share the link.

It also comes with a built-in command-line mode, so you can integrate it into your own scripts and automation tools.

▸ How to Use

Using PongoFileShare takes only a few steps:

1. Run the application.
Double-click PongoFileShare.exe to open the main window.
2. Select a file.
Click the Browse button and choose the file you want to share. The maximum allowed file size is 15 MB.
3. Click Upload.
Press the Upload button and wait for the progress bar to finish. The upload usually takes between a few seconds and one minute, depending on your connection speed.
4. Copy the link.
Once the upload succeeds, a public link will appear in the link box. The link is also copied to your clipboard automatically.
5. Share the link.
Paste the link anywhere you want. Anyone who opens it will be able to view or download the file directly in their browser.

Note: if the link is opened right after the upload, a short preparation page may appear. It will automatically open the file once it becomes available. This only happens the first time — afterwards the link goes straight to the file.
▸ Command-Line Usage

PongoFileShare can also be used from the command line, which makes it easy to integrate with scripts and automation tools.

Basic usage

Open Command Prompt or PowerShell in the folder where the application is located, then run:

PongoFileShare.exe "C:\path\to\your\file.pdf"

On success, the public link will be printed to the screen. On failure, an error message will be shown instead.

Save the link to a text file

PongoFileShare.exe "C:\Photos\image.jpg" > link.txt

The output file will contain only the public link, ready to be used by other programs.

Available options

Option Description
-h, --help Show help and usage information.
-v, --version Show the program version.

Exit codes

Code Meaning
0 Upload succeeded.
1 Upload failed.
2 Invalid arguments.

▸ Frequently Asked Questions

Q: What is the maximum file size?
A: The current limit is 15 MB per file.

Q: Do I need an account?
A: No. Simply download the application and start using it. No registration or sign-in required.

Q: Why does the link show a preparation page?
A: Right after an upload, the file may take a short moment to become available on the public link. The preparation page will automatically open the file once it is ready. This only happens the first time.

Q: How long is the file stored?
A: Files remain accessible for as long as they are kept on the server. Please contact the administrator for storage policies.

Q: Can I share the link with anyone?
A: Yes. Anyone with the link can open the file — no account or password required.

Q: What operating systems are supported?
A: PongoFileShare runs on Windows XP, Windows Vista, Windows 7, Windows 8, Windows 10, and Windows 11.

Q: Can I use PongoFileShare in my own script?
A: Yes. The application includes a command-line mode. See the Command-Line Usage section above.

Q: What happens if the upload fails?
A: The application automatically retries up to three times. If it still fails, a clear error message will explain the reason and suggest what to do next.
