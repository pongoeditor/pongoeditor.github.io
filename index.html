Pongo Hard Drive (PHD) is a free command-line utility for getting a closer look at your HDDs and SSDs.

PHD reads information reported by the storage device and presents it in a simple, straightforward format. You can use it to identify your drives, check their current health status, view temperature readings, inspect S.M.A.R.T. attributes, and review diagnostic information.

It can show details such as the drive model, manufacturer, serial number, firmware revision, capacity, sector size, interface information, supported features, temperature history, and other information available from the device.

PHD also includes built-in diagnostic functions for running quick or deeper drive tests, checking previous test results, and exporting drive information to TXT, JSON, or HTML reports.

Drive Detection

  • Automatically detects connected HDD and SSD drives.
  • Supports internal and external storage devices.
  • Displays detected drive number and basic device information.

Drive Information

  • Model name
  • Manufacturer / brand
  • Serial number
  • Firmware revision
  • WWN
  • Drive capacity
  • Sector information
  • Form factor
  • Rotation speed
  • Interface information

Drive Health Status

  • Check the current health status of the selected drive.
  • Displays the drive's reported health condition.
  • Shows available diagnostic and monitoring capabilities.

Temperature Monitoring

  • Current drive temperature
  • Airflow temperature when available
  • Minimum recorded temperature
  • Maximum recorded temperature

S.M.A.R.T. Information

  • Displays available S.M.A.R.T. attributes.
  • Attribute ID
  • Attribute name
  • Current value
  • Threshold
  • Raw value

Drive Diagnostics

  • Quick / short diagnostic test
  • Deep / long diagnostic test
  • Live diagnostic progress
  • Stop or cancel a running test
  • View previous diagnostic results
  • View diagnostic history
