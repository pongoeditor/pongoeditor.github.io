Welcome to PongoFileShare

PongoFileShare is a lightweight Windows desktop application that helps you upload files to a personal file-sharing space and gives you back a public link that anyone can open in a browser. No complicated setup, no command lines — just pick a file, click upload, and share the link.

▸ How to Use

Using PongoFileShare takes only a few steps:

1. Run the application.
Double-click PongoFileShare.exe to open the main window.
2. Enter your access key.
Paste your personal access key into the token field. This key is provided by the service administrator and is used to authorize your uploads.
3. Select a file.
Click the Browse button and choose the file you want to share. The maximum allowed file size is 15 MB.
4. Click Upload.
Press the Upload button and wait for the progress bar to finish. The upload usually takes between a few seconds and one minute, depending on your connection speed.
5. Copy the link.
Once the upload succeeds, a public link will appear in the link box. The link is also copied to your clipboard automatically.
6. Share the link.
Paste the link anywhere you want. Anyone who opens it will be able to view or download the file directly in their browser.

Note: if the link is opened right after the upload, a short preparation page may appear. It will automatically open the file once it becomes available. This only happens the first time — afterwards the link goes straight to the file.

▸ Frequently Asked Questions

Q: What is the maximum file size?
A: The current limit is 15 MB per file.

Q: Where do I get my access key?
A: The access key is provided by the service administrator. Please contact them if you do not have one.

Q: Why does the link show a preparation page?
A: Right after an upload, the file may take a short moment to become available on the public link. The preparation page will automatically open the file once it is ready. This only happens the first time.

Q: How long is the file stored?
A: Files remain accessible for as long as they are kept on the server. Please contact the administrator for storage policies.

Q: Can I share the link with anyone?
A: Yes. Anyone with the link can open the file — no account or password required.

Q: What operating systems are supported?
A: PongoFileShare runs on Windows XP, Windows Vista, Windows 7, Windows 8, Windows 10, and Windows 11.
