Pongo Hard Drive (PHD) is a small command-line tool that helps you see what your drives are actually reporting. It talks directly to the storage device, reads its health data, and lays it out in a format that's easy to read.

If you've ever wondered whether a drive is starting to fail, what its temperature has been over the years, or what the manufacturer is saying about its condition, PHD is meant for exactly that. It works with internal and external drives alike, on both spinning hard disks and modern solid-state drives.

Getting Started

Download PHD and extract it anywhere on your computer. The whole program fits in a single file, so you can keep it on a USB stick if you like.

Right-click phd.exe and choose Run as administrator. PHD needs elevated access to talk to the storage hardware. Without it, the drive list will be empty.

A banner appears and you land at a small prompt. Everything is typed in here. Start by typing:

phd > scan

This lists every drive PHD can see, one per line, with a number, model name, and type. Numbers start at 0 for the first drive. You will use that number for every command below.

Reading a Drive

info <ID> Shows the drive's identity: model, manufacturer, serial number, firmware, world-wide name, capacity, sector sizes, form factor, rotation speed, and which features it supports (SMART, TRIM, NCQ, APM).
status <ID> Reads the drive's own health verdict. The answer is GOOD, FAILED, or UNKNOWN if the drive did not report clearly. Also shows SMART capabilities and offline collection status.
temp <ID> Shows the current temperature, airflow temperature when available, and the lowest and highest temperatures the drive has ever recorded. Those historical values are stored inside the drive itself, so they show how hot the drive has actually been over its lifetime.
detail <ID> Prints the full SMART attribute table: attribute ID, name, current value, threshold, a status flag (OK, WARN, or BAD), and the raw counter value.
all <ID> Runs everything above in one go, plus the drive's error log and self-test history. Use this when you want the complete picture at once.

For example, to see everything on the first drive:

phd > all 0

Running a Diagnostic Test

PHD can ask the drive to run its own built-in self-test. This is not a PHD invention, it is a standard feature of the drive firmware. The drive tests itself and reports the result.

probe <ID> quick Starts a short self-test. Usually takes a minute or two. Good for a routine check.
probe <ID> deep Starts a long self-test. This scans the entire surface of the drive and can take several hours on a large disk. Run it when you suspect something is wrong.
probe <ID> report Shows the drive's test history: what tests have been run, when they ran, and whether they passed or failed.
probe <ID> stop Asks the drive to stop a test that is currently running.

While a test is running, a live progress bar appears. Press ESC at any time to abort.

Saving and Sharing

export <ID> txt Saves a plain-text report to the current folder.
export <ID> json Saves the same data as JSON, useful if you want to process it with another program.
export <ID> html Saves a formatted HTML report you can open in any browser or send to someone else.
submit <ID> Publishes the HTML report to this website. Once uploaded, PHD prints a link you can share. The report also appears in the submission list on this page.

Other Commands

scan Lists every drive PHD can find.
help Shows the built-in command reference.
about Shows program credits and website information.
clear Clears the screen and redraws the banner.
exit Closes the program. PHD removes any temporary files it created before quitting.

A Typical Session

phd > scan
phd > all 0
phd > probe 0 quick
phd > submit 0
phd > exit

That sequence lists the drives, shows a full report on the first one, runs a quick self-test, publishes the report to this site, and closes the program.

Feature Summary

Finding your drives

  • Lists every connected HDD, SSD, and NVMe device.
  • Shows the real model name instead of a device path.
  • Tags each drive by type so you know what you're looking at.

Device details

  • Model name and manufacturer
  • Serial number and firmware revision
  • World Wide Name (WWN)
  • Storage capacity and sector sizes
  • Form factor and rotation speed
  • Interface protocol (ATA / SATA)
  • Supported features such as SMART, TRIM, NCQ, and APM

Health and temperature

  • Drive's own health verdict: good, failed, or unclear
  • Current temperature
  • Airflow temperature when reported by the drive
  • Lowest and highest temperature ever recorded

SMART attributes

  • Full attribute list with ID and name
  • Current and worst values
  • Threshold and per-attribute status
  • Raw counter values, formatted for readability

Diagnostics

  • Quick scan for a fast check
  • Deep scan for a thorough surface test
  • Live progress, with ESC to abort
  • Review of previous test results

Saving and sharing

  • Export as plain text, JSON, or HTML
  • Publish a report to this site with one command
